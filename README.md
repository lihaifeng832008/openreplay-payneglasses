# openreplay-payneglasses

Corresponding Source of the modified OpenReplay components used by Payne Glasses, provided under the GNU Affero General Public License v3 (see `LICENSE`).

- Base: [OpenReplay](https://github.com/openreplay/openreplay) `v1.28.0`.
- This repository contains only the components we modify and run: `frontend/`, `player/` (agent web UI) and `assist/` (live session service). All other OpenReplay services run unmodified official `v1.28.0` releases; their source is available in the upstream repository.
- Changes: see `PG-CHANGES.md`. Build: see `BUILD.md`.
- The running version corresponds to the latest tag of this repository (`v1.28.0-pgN`).
